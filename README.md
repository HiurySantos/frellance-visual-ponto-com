# 🚀 Sobre o Projeto

Este projeto foi desenvolvido como freelancer para a escola de cursos profissionalizantes Visual Ponto Com.

O objetivo foi criar uma landing page moderna, responsiva e intuitiva, capaz de fortalecer a presença digital da instituição e facilitar o contato de novos alunos.

A interface foi construída com foco em:

- experiência do usuário
- apresentação institucional
- divulgação dos cursos
- captação de leads
- responsividade
- performance
- design moderno

Além disso, o projeto conta com integração com Google Analytics para monitoramento de acessos e comportamento dos usuários.
